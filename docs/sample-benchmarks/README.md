# Sample benchmark files (fictional)

**Every figure in these files is made up** for trying the Benchmarking tab
(Portfolio Management → Benchmarking, manual §7.50). They are not NCREIF,
Preqin, Cambridge Associates, Nareit or S&P data, and resemble them only in
layout. Upload your own licensed exports for real comparisons.

| File | Upload as | Layout |
|---|---|---|
| `ncreif-npi-industrial.csv`, `ncreif-npi.csv`, `ncreif-odce.csv` | Quarterly index (NPI Industrial, NPI, ODCE) | Quarter, Total, Income, Appreciation (%) |
| `preqin-vintage-quartiles.csv` | Vintage quartiles: Preqin | Wide: one row per vintage and strategy, IRR / TVPI / DPI quartiles |
| `cambridge-vintage-quartiles.csv` | Vintage quartiles: Cambridge Associates | Long: one row per vintage, strategy and metric |
| `reit-monthly-returns.csv` | Monthly returns (PME) | Date, then one column per series (decimals) |
