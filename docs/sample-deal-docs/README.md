# Sample deal documents (fictional, for testing)

Every document here is made up for testing the app: every page is marked
"SAMPLE – FICTIONAL – FOR TESTING ONLY", and the parties, addresses and
figures are invented, chosen to be consistent with Model Fund I's sample
assets and leases (`docs/sample-leases/`). Each phase that reads documents
adds its set here (plan decision 15).

## Tenant credit (phase D) — `tenant-credit/`

Generated by `scripts/sample-deal-docs/tenant_credit.cjs` from
`tenant-credit/expected.json`, which also holds the figures the app should
read and the flags it should raise. Upload them on the lease's **Tenant
credit** section (Leases tab, owners and editors).

| File | Lease | Type | What it tests |

"statements due" critical date is tested in the Node tests with a lease
clause added to a copy of an abstract.
