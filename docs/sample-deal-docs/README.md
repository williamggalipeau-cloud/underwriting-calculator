# Sample deal documents (fictional, for testing)

Every document here is made up for testing the app: every page is marked
"SAMPLE – FICTIONAL – FOR TESTING ONLY", and the parties, addresses and
figures are invented, chosen to be consistent with Model Fund I's sample
assets and leases (`docs/sample-leases/`). Each phase that reads documents
adds its set here (plan decision 15).

## Tenant credit (phase D) — `tenant-credit/`

Generated by `scripts/sample-deal-docs/tenant_credit.cjs` from
`tenant-credit/expected.json`, which also holds the figures the app should
read and the flags it should raise. Upload them on the lease's **Tenant
credit** section (Leases tab, owners and editors).

| File | Lease | Type | What it tests |
|---|---|---|---|
| desert-aero-credit-report-2025.pdf | 02 Airport Flex — Desert Aero Parts | Credit report, 10/15/2025, score 78 | Earlier score |
| desert-aero-credit-report-2026.pdf | 02 Airport Flex — Desert Aero Parts | Credit report, 10/20/2026, score 64, "Moderate risk (3 of 5)" | Falling-score flag; latest rating applied to the unit |
| desert-aero-financial-statements-fy2024.pdf | 02 Airport Flex — Desert Aero Parts | Reviewed statements, FY2024; debt / equity 0.60 | Leverage baseline |
| desert-aero-financial-statements-fy2025.pdf | 02 Airport Flex — Desert Aero Parts | Reviewed statements, FY2025; debt / equity 1.05, current ratio 1.31 | Rising-leverage flag; ratio checks; rent as % of revenue |
| jordan-ramos-personal-financial-statement-2024.pdf | 02 Airport Flex — guarantor Jordan A. Ramos | Personal financial statement, 6/30/2024 | Stale-statement flag (over 12 months) |
| cascade-cabinet-credit-report-2026.pdf | 03 Route 9 — Cascade Cabinet Works | Credit report, 9/1/2026, score 82 | A single clean report (no flags) |

None of the sample leases requires periodic financial statements, so the
"statements due" critical date is tested in the Node tests with a lease
clause added to a copy of an abstract.

## Deal and fund documents (phase E) — `deals/`

Generated by `scripts/sample-deal-docs/deal_docs.py` (text and abstracts
together, so every quote is a sentence of the PDF) and printed with
`node scripts/sample-deal-docs/print_html.cjs docs/sample-deal-docs/deals`.
The abstracts in `deals/abstracts/` pass the app's local check against the
PDF text. They are made for testing, not by the CREparser connector, so
they are marked "not connector-validated" even for types the connector can
validate (OM, rent roll, T-12, LOI); review them with Claude to validate.
